## Installation

To install this library using NPM, run the following command:

```Shell
# under the `type-sea` alias
npm install type-sea@npm:@tygo-van-den-hurk/type-sea

# normally
npm install @tygo-van-den-hurk/type-sea
```

Installing it as an alias is the preferred method, as it is the difference between:

```TypeScript
import { ... } from 'type-sea';
// and:
import { ... } from '@tygo-van-den-hurk/type-sea';
```

To install from [GitHub' NPM registry](https://npm.pkg.github.com/) add the `--registry=https://npm.pkg.github.com/` option. This might require a personal access token from GitHub to function correctly.
